# 午市厨房

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查及生产构建：

```sh
npm run typecheck
npm run build
```

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。

## 服务承诺

客人点单后会在订单卡上看到三种承诺，接受的一刻即冻结：

| 承诺 | 期限 | 费用 | 说明 |
| --- | --- | --- | --- |
| 普通 | 保留原始等待 | 无 | 按交付品质结算 |
| 加急 | 压缩到剩余的 60%（至少 8 秒） | 加收 25% 附加费 | 接单即入账，不会重复收取 |
| 分次 | 保留原始等待，拆成两份 | 接单预收全款 | 首份交付后安抚 12 秒，只推迟离店，不改变菜品温度 |

- 承诺的价格、期限与菜品要求是接单快照，没有命令可以中途改回普通承诺。
- 每位客人只能同意一次延期；延期把承诺截止推后 20 秒，餐厅付出 10% 折扣。
- 截止当刻仍可交付，严格超过才离店；同刻离店按离店时点、再按订单号排序。
- 分次订单已上一部分后可以放弃剩余，只退未完成份额；超时则按未完成份额补偿并退款，每张承诺只结算一次。
- 面板同时显示原始等待、承诺截止和补偿状态；起锅与装盘仍使用原有共享设备。
